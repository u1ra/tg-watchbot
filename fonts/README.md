# 字体说明

本目录包含 **资源圆体（Resource Han Rounded CN）**，用于 Web 管理面板界面显示。

- 作者：Cyano Hao
- 来源：https://github.com/CyanoHao/Resource-Han-Rounded （v0.990，CN 版本）
- 授权：SIL Open Font License 1.1（全文见同目录 `OFL.txt`）
- 文件：`rhr-cn-400.woff2`（Regular）、`rhr-cn-700.woff2`（Bold）
- 处理：由官方 TTF 转为 WOFF2，并移除了扩展 B 区及以后的罕用字平面（面板用不到；基本区、扩展 A 区、兼容汉字、日文假名、全角符号均完整保留）
